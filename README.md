# Social media operating system

This repository is a personal operating system for AI-assisted content: strategy, ideas, briefs, reusable workflows, and learning across channels. Start small, publish consistently, and improve from audience response.

## Start here
1. Capture the audience, claim, and evidence gap in [the idea bank](ideas/idea-bank.md).
2. Select ideas using the criteria in [content pillars](strategy/content-pillars.md).
3. Copy the [post brief](templates/post-brief.md) into `drafts/YYYY-MM-DD-topic-platform.md`.
4. Draft and review against the [editorial guide](strategy/editorial-guide.md) and [workflow](workflow.md).
5. Publish, record the live link and results in the brief, and use the [repurposing template](templates/repurpose.md) when an idea merits other formats.

## Weekly operating rhythm
Choose 2–3 ideas, finish one anchor piece, adapt it to suitable formats, and review results. Prioritize useful replies and qualified conversations alongside reach. Keep private notes and unapproved company information out of this public repository.

AI can help turn notes into options and critique drafts. It should never invent facts, results, quotes, or experiences. Human review controls what goes live.
